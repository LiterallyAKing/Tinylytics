### wishes:
- automatic handling / logging of analytics most people would want, like session time, level time, etc
- - it would be great to include two linked pieces of data together as one log. for example, i want to log the number of moves in a level, it would be good to log the number of moves and the level number along with it. same idea with level time
- if you have many components on one object and you intend to use a custom trigger call, getting the correct script in code is not especially user friendly. best case is you have a bunch of public variables for the script and you drag and drop. i guess you could use the metric name to find the script you want right now, but that's probably slow, a little unintuitive, and would likely run into problems because the metric names don't have to be unique.
- unity has an OnApplicationQuit method which is great for calling a method to log the end of a session, calculating time played or whatever other data you might want. seems like this doesn't work with the current implementation of the analytics posting. perhaps there isn't enough time to send the data before the application closes.

- would prefer option to add the analytics manager myself instead of it defaulting to creating an object in the scene. Maybe it could check for the script in the scene to see if the object needs to be created first.
